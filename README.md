# 学习工作台

计划、笔记、卡片复习、番茄钟、统计、课表与临时安排、教材导入、AI 出卷和错题本，合在一个页面里的自学工具。纯静态站点，用浏览器打开即可使用。

这一版有吉祥物「林遥学姐」，专注页是二次元风格的房间，并加强了教材导入。

在线地址：<https://smith1088.github.io/just-self-study/>

## 添加到 iPhone 主屏幕

用 Safari 打开上面的地址，点底部「分享」→「添加到主屏幕」。

## 数据与密钥

学习数据和 AI API Key 只保存在你的设备上（浏览器本地存储），不会写入本仓库，也不会上传到 GitHub。API Key 只在你发起请求时发给你自己选择的服务商，不会发给其他地址。
